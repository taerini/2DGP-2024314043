# PRD — 소닉 애니메이션 뷰어 (v3: 장면 시나리오)

> 근거 자료: `PRE-PRD.md`, `sonic-sprite.png`, 강의 자료 `LEC 09 애니메이션 뷰어 제작 실습`, 이전 실습 `Labs/LEC08_Animation/animation_viewer.py`
>
> 변경 이력
> - v1: 10개 동작을 차례로 5회 재생, 1초 정지, 무한 순환 (`lec09-sonic-viewer` 브랜치, `main` 병합 완료)
> - v2: 사용자 요청으로 **장면 시나리오** 방식으로 변경. 시트의 각 줄을 정해진 순서와 이동 경로에 따라 한 번 재생하고 마지막 포즈에서 멈춘다.
> - v3: 공 차기 이후 장면 수정. 6번째 줄로 달려가 멈춘 뒤 3번째 줄로 차기, 공이 모서리에서 튕겨 소닉 머리 위로 사라짐,

## 1. 목표

`sonic-sprite.png`의 10개 줄(동작)을 이용해 짧은 이야기를 한 번 재생하는 뷰어를 만든다.

> 소닉 A가 왼쪽 아래에서 등장해 걷다가 공으로 변해 튕긴다. 멀리서 소닉 B가 다가와 공을 찬다. 공은 화면 모서리에 부딪혀 소닉 B의 머리 위로 날아가 사라지고, 소닉 B는 공을 따라 뛰어올랐다가 추락한 뒤 미끄러져 이동하고 작게 뛰어 포즈를 취한다.

## 5. 장면 시나리오

모든 장면은 앞 장면이 끝난 위치·배율·방향에서 바로 이어진다. 장면 사이에 정지 구간은 없다.
방향 ← 는 시트 그림을 좌우 반전해 그린다는 뜻이다. 위치는 발 위치, 높이는 지면 위 높이다.

| 2  | 2  | A →    | 오른쪽으로 걷기                           | x 100 → 1000                                 | 4.5초 (200px/s) | 0.08        |

### FR-1 창과 출력

- 1200 × 600 캔버스를 열고, 매 화면 `clear_canvas()` → 그리기 → `update_canvas()` 순서로 갱신한다.
- 프레임은 발 위치 `(x, y)`를 아래 변 중앙으로 하여 `배율` 만큼 확대해 그린다. ← 방향은 `clip_composite_draw(..., 0, 'h', ...)`로 좌우 반전한다.
- 화면 왼쪽 위에 현재 장면 이름을 표시한다(pico2d 패키지의 `ConsolaMalgun.ttf` 사용).

### FR-2 시간과 장면 진행

- 모든 움직임과 프레임 전환은 실제 경과 시간(`get_time()`)으로 계산한다.
- 장면 진행률 `p = 경과 시간 / 장면 시간`(0~1)으로 위치·높이·배율을 보간한다. 장면 시간이 다 되면 끝 값에 정확히 맞추고 다음 장면으로 넘어간다.
- 이동하는 장면에서는 장면이 끝날 때까지 프레임을 처음부터 끝까지 반복 재생한다. "(1회)"라고 적은 장면은 프레임을 한 번만 재생한다.

### FR-3 공 튕김 (장면 5, 6, 공 대기)

- 튕김 한 번의 높이는 `h = 4 × 최고높이 × q × (1 - q)`, `q`는 그 튕김 안에서의 진행률. 매 튕김의 시작과 끝은 지면이다.
- 장면 5: 0.36초마다 1번, 최고 120px, 4번.
- 장면 6: 0.45초씩 2번, 최고 100px → 60px, 공 그림은 반전.
- **공 대기**: 장면 6이 끝난 뒤부터 공을 찰 때까지 공은 x = 700에서 제자리로 작게 튕긴다(최고 16px, 0.36초 주기, 공 프레임 계속 재생).

### FR-4 소닉 B의 원근 (장면 7, 8)

- 장면 7에서 소닉 B는 시작점보다 훨씬 위(발 y 380)에서 작게(1.5배) 나타난다.
- 장면 7, 8 동안 배율은 커지고(1.5 → 2.5 → 4) 발 y는 내려온다(380 → 260 → 100). 장면 8이 끝나면 정확히 시작점 `(100, 100)`, 원래 크기(4배)다.
- 멀리 있는 소닉 B는 공보다 먼저(뒤에) 그린다.

### FR-5 공 차기 (장면 9)

- 소닉 B는 6번째 줄(dash) 프레임을 0.05초씩 반복하며 450px/s로 오른쪽으로 달린다. 달리는 동안에는 차지 않는다.
- 차는 그림(3번째 줄 5번째 프레임)의 오른쪽 가장자리가 공 그림의 왼쪽 가장자리에 닿는 위치에서 멈춘다.
- 멈춘 뒤 3번째 줄(run) 6프레임을 0.08초씩 한 번 재생한다. 5번째 프레임이 나오는 순간 공을 찬다. 끝난 뒤에는 6번째 프레임을 유지한다.
- 찬 공은 두 구간을 직선으로 날아간다(공 프레임은 계속 재생).
  1. 오른쪽 위 모서리까지 0.5초: 공 그림의 오른쪽·위 끝이 화면 오른쪽·위 끝에 닿는 곳
  2. 모서리에 부딪혀 **반전**, 왼쪽 위 대각선으로 0.6초: 소닉 B의 x 위, 공 그림 전체가 화면 위로 나간 곳
- 두 번째 구간이 끝나면 공은 사라지고(더 이상 그리지 않음) 장면 10으로 넘어간다.

### FR-6 뛰어오름과 추락 (장면 10)

- 공을 따라 뛰어오른다: leap 1~6번 프레임을 0.12초씩 보여 주는 0.72초 동안 높이 0 → 300px(처음엔 빠르고 끝에서 느려짐: `300 × (1 - (1-p)²)`). x는 그대로. 최고점에서도 그림 위 끝이 화면 안(약 576px)에 있다.
- 이어서 7~8번 프레임을 0.1초씩 번갈아 보여 주며 1.0초 동안 **오른쪽 대각선 아래로** 떨어진다. 높이 300px → 0(점점 빨라짐: `300 × (1 - p²)`), x는 오른쪽으로 150px.
- 지면에 닿으면 장면 11로 넘어간다.

### FR-7 마무리 (장면 11, 12, 13)와 종료

- 장면 11: 착지한 자리에서 skid 8프레임을 0.12초씩 한 번 재생한다. 1~4번 프레임 동안은 오른쪽으로 x 922까지, 5~8번 프레임 동안은 왼쪽으로 x 200까지 이동한다. 그림 방향은 오른쪽 그대로(반전 없음).
- 장면 12: x 200에서 아주 약간(최고 30px) 뛰어오르며 pose 1·2번 프레임을 0.15초씩 재생한다.
- 장면 13: 지면에 착지해 pose 3·4·3·4번 프레임을 0.15초씩 재생하고 마지막(4번) 프레임을 유지한다. 시나리오는 반복하지 않는다.
- 창 닫기 버튼(`SDL_QUIT`)이나 ESC로 언제든지 종료하고, 종료 시 `close_canvas()`를 호출한다.

## 6. 비기능 요구사항

- 메인 루프는 `delay(0.01)` 정도로 CPU 사용을 낮춘다. 움직임 속도는 루프 속도와 무관해야 한다.
- 장면 경로·시간 값은 장면 데이터로 모아 두어, 수치를 바꿀 때 로직을 고치지 않아도 되게 한다.
- 변수와 함수 이름은 LEC08 `animation_viewer.py`의 관례(대문자 상수, 짧은 한국어 주석)를 따른다.

## 7. 코드 구조 (권장)

```
상수      WIDTH, HEIGHT, SCALE, GROUND_Y, START_X, ...
데이터    FRAMES = {이름: [(l, b, w, h), ...]}        줄별 프레임
          SCENES = [{name, actor, frames, frame_time, duration, 경로 값...}, ...]
객체      Actor: x, y(발), height(지면 위 높이), scale, direction, frames, frame_index, visible
함수      handle_events()  draw_frame(frame, x, y, scale, direction)
          start_scene(i)   update(dt)   draw()
메인      open_canvas → 루프(handle_events, update, draw, delay) → close_canvas
```
